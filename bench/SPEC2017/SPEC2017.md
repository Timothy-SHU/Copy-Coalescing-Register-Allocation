# Dependencies:

- Rust and cargo:
  `curl https://sh.rustup.rs -sSf | sh`
- td-extract:
  `cd td-extract`
  update .bashrc with
  `export LD_LIBRARY_PATH="/usr/local/lib:$LD_LIBRARY_PATH"`
  &nbsp;
  ```
  ./run.sh
  cp target/release/libtd_extract.so ../function-inlining-pass
  ```

- llvm-18
  ```
  wget https://apt.llvm.org/llvm.sh
  chmod +x llvm.sh
  sudo ./llvm.sh 18 all
  sudo apt install libzstd-dev # needed library
  ```
  update .bashrc with:
  `export PATH="$PATH:/usr/lib/llvm-18/bin"`

- htd
  ```
  git clone https://github.com/mabseher/htd
  cd htd
  cmake .
  make
  sudo make install
  ```
# Directories:
- `.` (initially has `cpu2017-1_0_5.iso`, `mibenchscript.sh`, `spec2017script.sh`, `myflags.xml`, `myexpcfg.cfg`)
- `mibench_src`
- `mibench`
- `spec2017`
- Files generated by spec with different flags, without linking:
    - `-fno-inline_-Os_-S_-emit-llvm` (to be fed to our algorithm and to asplos tool [after removing NoInline/OptimizeNone attributes from all functions])
    - `-Os` (to compare against it)
    - `-fno-inline_-Os` (to compare against it; mostly for sanity check, to verify that our algo consistently gives improvement over this)
    - `function-inlining-pass` (where we run our algorithm inside an LLVM pass)

- Get binaries/LLVM IR from SPEC2017:

  ```
  # 28 (16+12) programs in total (excluding programs using Fortran, and compiling some benchmarks using the appropriate C++ standard)
  cp spec2017script.sh spec2017
  cd spec2017
  chmod +x spec2017script.sh
  . shrc
  # IRs for individual sources to be used by our algorithms
  ./spec2017script.sh $LLVM_DIR "-fno-inline -Os -S -emit-llvm" 500.perlbench_r 502.gcc_r 505.mcf_r 520.omnetpp_r 523.xalancbmk_r 525.x264_r 531.deepsjeng_r 541.leela_r 557.xz_r 508.namd_r 510.parest_r 511.povray_r 519.lbm_r 526.blender_r 538.imagick_r 544.nab_r 600.perlbench_s 602.gcc_s 605.mcf_s 620.omnetpp_s 623.xalancbmk_s 625.x264_s 631.deepsjeng_s 641.leela_s 657.xz_s 619.lbm_s 638.imagick_s 644.nab_s
  ```

  Note: the previous command emits llvm IR, and spec2017 will only manage to compile individual sources, but will fail afterwards because it will try to link using clang, which does not support emitting llvm-ir linked code. This doesn't matter because we'll do the linking later after after converting the units to binary.

  ```
  # compiled binaries
  ./spec2017script.sh $LLVM_DIR "-Os" 500.perlbench_r 502.gcc_r 505.mcf_r 520.omnetpp_r 523.xalancbmk_r 525.x264_r 531.deepsjeng_r 541.leela_r 557.xz_r 508.namd_r 510.parest_r 511.povray_r 519.lbm_r 526.blender_r 538.imagick_r 544.nab_r 600.perlbench_s 602.gcc_s 605.mcf_s 620.omnetpp_s 623.xalancbmk_s 625.x264_s 631.deepsjeng_s 641.leela_s 657.xz_s 619.lbm_s 638.imagick_s 644.nab_s
  ```

# Run our LLVM pass
  ```
  cd function-inlining-pass

  chmod +x config_build_pass.sh
  chmod +x config.sh
  chmod +x myrun.sh

  ./config_build_pass.sh

  # Running the pass on a particular .ll file
  [LD_PRELOAD=$CLANG_ASAN] opt -load-pass-plugin=./libFunctionInliningPass.so -passes=function-inlining-pass ../dump/ll_inputs/<input_filename>.ll -S [-o ../dump/ll_outputs/<output_filename>.ll | -disable-output] 

  # Running the pass on benchmarks
  ./myrun.sh units -fno-inline_-Os_-S_-emit-llvm 500.perlbench_r 502.gcc_r 505.mcf_r 520.omnetpp_r 523.xalancbmk_r 525.x264_r 531.deepsjeng_r 541.leela_r 557.xz_r 508.namd_r 510.parest_r 511.povray_r 519.lbm_r 526.blender_r 538.imagick_r 544.nab_r 600.perlbench_s 602.gcc_s 605.mcf_s 620.omnetpp_s 623.xalancbmk_s 625.x264_s 631.deepsjeng_s 641.leela_s 657.xz_s 619.lbm_s 638.imagick_s 644.nab_s
  cd ..
  ```
# Linking
To link benchmarks under a particular directory, use:
`./link2.sh <directory> <files>`
For example,
`./link2.sh -fno-inline_-Os_-S_-emit-llvm 500.perlbench_r 502.gcc_r 505.mcf_r 520.omnetpp_r 523.xalancbmk_r 525.x264_r 531.deepsjeng_r 541.leela_r 557.xz_r 508.namd_r 510.parest_r 511.povray_r 519.lbm_r 526.blender_r 538.imagick_r 544.nab_r 600.perlbench_s 602.gcc_s 605.mcf_s 620.omnetpp_s 623.xalancbmk_s 625.x264_s 631.deepsjeng_s 641.leela_s 657.xz_s 619.lbm_s 638.imagick_s 644.nab_s`
After our algorithm is run, use
`./link2.sh outputs/output_<timestamp>/spec2017_pass_ll_outputs_units <files>`
