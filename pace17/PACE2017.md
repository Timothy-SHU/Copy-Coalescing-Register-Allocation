# Treewidth finder for PACE 2017 competition

In firsthand you should build the project.

```bash
./build.sh
```

The format specification of the input graph and output decompositions follow those of the [PACE 2017](https://pacechallenge.wordpress.com/pace-2017/track-a-treewidth/) challenge (Appendix A, B)

You should put your all input files under the `/input` directory and run the following command to get outputs in the `/output` directory:

```bash
./run.sh
```

I limited the solver with 30 seconds time limit (TL), which is usuall satisfactory. If you are not satisfied with the found treewidth, you can increase the TL in the `run.sh` script.
